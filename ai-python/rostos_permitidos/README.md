# Diretório de Faces Autorizadas

Coloque neste diretório as fotos dos usuários autorizados para o reconhecimento facial de 1º fator.

### Convenção de Nomes
O nome do arquivo (sem a extensão) será automaticamente registrado como o nome do usuário identificado pelo sistema.

Exemplos:
- `roberto.jpg` -> Usuário identificado: **roberto**
- `maria.png`   -> Usuário identificado: **maria**
- `ana.jpeg`    -> Usuário identificado: **ana**

### Requisitos das Imagens
- Formatos suportados: `.jpg`, `.jpeg`, `.png`
- O rosto deve estar nítido, bem iluminado e frontal.
- Apenas um rosto por imagem de referência.
